# Changelog

Newest first.

- 2026-09-02 — **Fixed the plugin install path, which had been broken since the split.** All three domain
  marketplaces declared `"strict": true` while carrying no `.claude-plugin/plugin.json`. That combination
  is invalid (strict:true *requires* a plugin.json; strict:false means the marketplace entry is the whole
  definition), so every `marketplace sync` against them failed. Set to `false` in all three
  — riley-thinking-skills 1.1.1, riley-pm-skills 1.0.1, riley-coding-skills 1.0.1. Separately, the four
  plugins installed on the account were still the **pre-split 17 August packages**: `anthropic-example-skills`
  was serving the old combined `anthropic/` folder (13 skills, including the coding ones), and
  `superpowers` had never been installed at all. Removed and reinstalled from the three domain
  marketplaces — 8 plugins, 51 of 53 skills live. `claude-api` and `claude-academy-guide` still do not
  load: their frontmatter `description` exceeds the ~1024-character limit and both are vendored, so
  fixing them means either a re-vendor against a newer upstream or a documented local patch.

- 2026-08-23 — Made this hub the **control plane** for the whole setup, not just skills. Added
  `routines/` (scheduled triggers backed up as restore-ready JSON, generated by
  `scripts/format_routines.py`), `config/` (a portable, secret-free `settings.json` baseline), and a new
  `backup-claude-setup` skill under `control-plane/` that snapshots routines + settings to this repo and
  restores them. Registered it in `marketplace.json` as the `riley-control-plane` plugin (9 plugins now)
  and bumped the marketplace to 2.1.0. Skills themselves still route to the domain repos via
  `publish-skill-to-github`.

- 2026-08-23 — Split this library into three domain repos. Skills now live in
  [riley-pm-skills](https://github.com/rileytrottier23/riley-pm-skills) (16),
  [riley-coding-skills](https://github.com/rileytrottier23/riley-coding-skills) (19), and
  [riley-thinking-skills](https://github.com/rileytrottier23/riley-thinking-skills) (17). Removed the
  in-repo skill folders (`pm/`, `personal/`, `anthropic/`, `third-party/`); full pre-split history
  remains in git. Rewrote `marketplace.json` as an **aggregator** that sources all 8 plugins from the
  three repos, so the existing `riley-claude-skills` marketplace keeps working as a combined hub
  (`/plugin marketplace update` to pick it up).
- 2026-08-23 — Added `third-party/obra-superpowers`. 48 skills total.
- 2026-08-23 — Added `third-party/obra-elements-of-style`, vendored from obra@05fc4f0. 34 skills total.
- 2026-08-22 — Added `personal/publish-skill-to-github`. 33 skills total.
